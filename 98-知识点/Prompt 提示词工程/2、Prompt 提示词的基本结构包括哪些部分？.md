# 一、回答重点

一个完整的 Prompt 提示词通常包含四个核心部分：指令、上下文、输入数据和输出指示。

==指令（Instruction）==是告诉 AI 要做什么，这是最核心的部分。比如 "请总结这篇文章"、"帮我翻译成英文"、"分析这段代码的问题"。指令要清晰具体，不要模棱两可。

==上下文（Context）==是提供背景信息，帮助 AI 更好地理解任务。比如 "我是一个零基础的编程学习者"、"这是一份技术文档"、"目标读者是小学生"。上下文让 AI 知道应该用什么角度、什么风格来处理任务。

==输入数据（Input Data）==是需要 AI 处理的具体内容。可以是一段文字、一段代码、一组数据等。建议用分隔符（如三个反引号）把输入数据和其他部分区分开，让结构更清晰。

==输出指示（Output Indicator）==是告诉 AI 期望的输出格式和要求。比如 "请用 JSON 格式输出"、"字数控制在 500 字以内"、"用表格形式展示结果"。明确输出指示能让 AI 的输出更符合预期。

## 1、示例结构

```
# 指令
请帮我总结以下文章的核心观点

# 上下文
这是一篇关于 AI 技术发展的行业报告，目标读者是技术决策者

# 输入数据

# 输出指示
- 用 3-5 个要点总结
- 每个要点不超过 50 字
- 用 Markdown 列表格式输出

```

# 二、扩展知识

实际使用中，不是每个提示词都需要包含四个部分。简单任务可能只需要指令就够了，负载任务则需要完整结构。==要根据具体情况灵活运用。==

指令的写法很有讲究。要用明确的动词开头，比如 "总结"、"翻译"、"分析"、"生成" ，而不是模糊的 "帮我看看"、"处理一下" 。指令越具体，AI 的执行效果越好。如果任务复杂，可以把指令拆分成步骤，让 AI 按步骤执行。

上下文信息经常被忽略，但其实很重要。AI 不知道你的背景、你的目标、你的偏好，需要你主动提供。比如让 AI 写文章，如果不说明目标读者是谁，AI 可能写出来的风格完全不符合预期。好的上下文能让 AI 输出更贴近需求。

分隔符的使用是个小技巧但很实用。常用的分隔符有三个反引号、三个引号、XML 标签等。分隔符能清楚地界定哪些是指令、那些是数据，避免 AI 混淆。特别是处理用户输入时，分隔符还能防止提示词注入攻击。

输出格式的指定可以大大提升后续处理效率。如果你需要在程序中解析 AI 的输出，JSON 格式最方便。如果是给人看的内容，Markdown 格式更易读。如果是数据对比，表格格式更直观。明确告诉 AI 输出格式，能省去很多后期处理的麻烦。
