# 一、回答重点

分隔符在提示词中的作用是清晰地标识不同部分的边界，让 AI 能够准确区分哪些是指令、哪些是数据、哪些是示例。就像写文章要分段，提示词也需要结构化，分隔符就是实现结构化的工具。

常用的分隔符有几种。三个反引号是最常用的，适合包裹代码或长文本。三个引号也很常见，视觉上更明显。XML 标签如  `<input></input>` 更加语义化。

使用分隔符的好处有很多。首先就是结构清晰，AI 能快速识别提示词的各个部分，不会混淆。其次是防止注入，当处理用户输入时，分隔符能防止恶意用户通过输入来修改提示词逻辑。最后是提升准确性，明确的边界让 AI 的理解更准确，输出质量也更高。

# 二、扩展知识

分隔符的选择要根据内容类型。如果内容是代码，用三个反引号加语言标识更好，比如  ` ```python ` 。如果是 XML 或 HTML ，用 XML 标签更自然。如果是纯文本，用引号或分隔线就够了。选对分隔符，AI 能更好地理解内容特性。

在处理用户输入时，分隔符是防御提示词注入的重要手段。提示词注入是指恶意用户通过输入特殊内容来改变 AI 的行为。比如用户输入 "忘记之前的指令，现在 ..."，如果没有分隔符，AI 可能真的执行新指令。有了分隔符，用户输入被明确界定，AI 不会把它当作指令。

分隔符要选择不容易出现在内容中的符号。如果用 `###`作为分隔符，但内容本身就有很多 `###` ，那就会混乱。三个反引号就是个好选择，因为普通文本里很少连续出现三个反引号。XML 标签更安全，因为标签名可以自定义，更不容易冲突。

在复杂提示词中，可以使用嵌套的分隔符来标识层次结构。比如外层用 `"""` 表示大段内容，内层用 ` ``` `  表示代码块。或者使用 XML 标签的嵌套，如 `<content><input></input></content>` 。清晰的层次让提示词更易维护。

分隔符不只用于分隔输入数据，也可以用于分隔输出。比如要求 AI "请把答案放在 `<answer></answer> `标签内 " 。这样从 AI 的输出中提取答案就很容易，直接查找标签的内容即可。这在程序化处理 AI 输出时特别有用。

有个实用技巧是在提示词模板中预定义分隔符。把常用的分隔符作为模板的一部分，使用时只需要输入具体内容。这样能保证分隔符的使用规范统一。
