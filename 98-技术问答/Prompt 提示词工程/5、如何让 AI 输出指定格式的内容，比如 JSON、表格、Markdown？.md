# 一、回答重点

让 AI 输出指定格式的关键是在提示词中明确告诉它想要什么格式，并且最好提供示例。

最直接的方法是在提示词中明确说明输出格式。比如 "请使用 JSON 格式输出"、"请使用 Markdown 表格展示"、"请用有序列表回答" 。大部分情况下，AI 都能理解并按要求输出。

更可靠的方法是提供格式示例。不仅说明要什么格式，还给出一个具体的例子，让 AI 模仿。比如要 JSON 格式，就给一个 JSON 的结构示例；要表格，就画一个表格的样子。AI 看到示例后，会更准确地按照格式输出。

## 1、JSON 格式示例

```
请分析以下用户数据，并用 JSON 格式输出，格式如下：

{
  "name": "用户名称",
  "age": 年龄数字,
  "tags": ["标签1", "标签2"]
}

用户数据：[具体数据...]

```

## 2、Markdown 表格示例

```
请对比三个产品的特点，用 Markdown 表格展示：

| 产品名称 | 价格 | 特点 |
|---------|------|------|
| 产品A | $100 | 特点描述 |

```

# 二、扩展知识

对于 JSON 格式，还可以更进一步指定数据类型和字段约束。比如明确哪些字段是必需的、哪些是可选的，数值型字段的范围，字符串字段的长度限制等，这样 AI 输出的 JSON 更规范，后续程序处理起来更容易。

有些 AI 服务提供了结构化输出功能，可以强制 AI 按指定的 JSON Schema 输出。OpenAI 的 Function Calling、Anthropic 的 Tool Use 都支持这个功能。这比纯文本提示词更可靠，因为是在 API 层面强制格式，AI 无法偏离。

表格格式要注意对齐和可读性。Markdown 表格虽然简洁，但对于复杂数据可能不够直观。可以根据场景选择：在文档中用 Markdown 表格，在数据分析中用 CSV 格式，在网页中用 HTML 表格。告诉 AI 使用场景，它会选择更合适的格式。

代码格式也是常见需求。要让 AI 输出代码时带上语言标记和代码块，可以在提示词中说明 "请用代码块格式输出吗，并标注语言类型"。这样输出的代码有语法高亮，更易阅读。

有时候 AI 会在格式化输出前加一些说明文字，比如 "好的，这是 JSON 格式的结果：" 。如果需要纯粹的格式化内容，可以在提示词中强调 "只输出 JSON，不要有任何其他文字" 或者 "直接输出表格，不要有额外说明"。

格式化输出失败的常见原因是提示词不够明确。"用表格展示" 不如 "用 Markdown 表格格式展示，包含表头和分割线" 清晰。"输出 JSON" 不如 "输出有效的 JSON 格式，包含大括号，字段用双引号，字符串值也用双引号" 详细。越具体，成功率越高。

如果一次输出不符合预期，可以追加提示词要求修正。比如 "刚才的输出格式不对，请严格按照 JSON 格式重新输出"。AI 通常能理解并改进。但这会增加 Token 消耗，最好是一开始就把格式要求写清楚。
